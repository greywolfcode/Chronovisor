# Chronovisor Archive Generator

This is a tool for createing custom chat archives.

## Dependencies

- [textual](https://github.com/Textualize/textual)

## Mac UI

As this archive generator is built on textual, the UI may not look correct on default Mac OS. more information can be found [here](https://textual.textualize.io/FAQ/#why-doesnt-textual-look-good-on-macos).
